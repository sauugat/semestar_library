Explain 3NF vs BCNF with a quick example
KA
KYANA AI • B.TECH CSE CURRICULUM COPILOT
3NF requires no transitive functional dependency. BCNF is stronger: for every non-trivial functional dependency X → Y, X must be a candidate super-key.
3NF Rule: Allows Y to be a prime attribute even if X is not a super key.
BCNF Rule: Eliminates anomalies where non-prime attributes determine candidate keys.
